# VoiceLog

VoiceLog is a Voice-to-Text and AI Summarization application built using Streamlit and OpenAI Whisper.

## Features

- Upload MP3 or WAV audio files
- Convert speech to text
- Generate AI-based summaries
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- OpenAI Whisper
- Transformers (Hugging Face)

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
pip install streamlit openai-whisper transformers torch sentencepiece
```

3. Run the application

```bash
streamlit run app.py
```
